# Atribuição de dados — Olist Brazilian E-commerce

Os arquivos em `data/*/` derivam do dataset **Brazilian E-commerce Public Dataset by Olist**
(Kaggle: `olistbr/brazilian-ecommerce`), licenciado sob
**Creative Commons Attribution-NonCommercial-ShareAlike 4.0 (CC BY-NC-SA 4.0)**.

- Atribuição: Olist + contribuidores (ver Kaggle para citação completa).
- Uso **não comercial** apenas — verificar o enquadramento deste projeto (NC) **antes** de publicar este diretório em repositório público ou fazer deploy com os Parquets no bundle.
- Compartilhamento pela mesma licença: derivações destes Parquets seguem CC BY-NC-SA 4.0.
- Tradução de categorias via `product_category_name_translation.csv` (do próprio dataset).
